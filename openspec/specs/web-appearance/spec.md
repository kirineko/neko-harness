# web-appearance Specification

## Purpose

定义 Web 端的外观偏好：可选主题与聊天排版的取值范围、保存位置、首屏应用方式与可读性保证，使用户能按个人习惯和光线环境调整界面而不影响会话数据与其他前端。

## Requirements

### Requirement: Web 主题选择

Web SHALL 提供三套主题：「樱花」（蓝粉白浅色，默认）、「纸白」（中性冷灰白浅色）与「夜墨」（深蓝灰深色，非纯黑）。主题 SHALL 作用于全站：导航、弹层、聊天内容、输入卡片、设置页、代码高亮与 diff、滚动条、表单控件与焦点环。三套主题 MUST 共用同一套 design tokens，仅取值不同。Web MUST NOT 提供「跟随系统」选项。

#### Scenario: 默认主题

- **WHEN** 用户从未保存过外观偏好并打开 Web UI
- **THEN** 界面呈樱花主题，与本变更之前的外观一致

#### Scenario: 切换主题

- **WHEN** 用户在外观页选择「夜墨」
- **THEN** 全站立即呈深色，包括侧栏、顶栏、弹层、聊天气泡、输入卡片、代码块与设置页，且浏览器原生滚动条与表单控件也使用深色方案

#### Scenario: 无遗留浅色区域

- **WHEN** 任一深色或浅色主题下浏览聊天、工作区栏、设置页、技能市场与关于页
- **THEN** 不存在沿用其他主题底色的区域；仅二维码保持白底以保证可扫描

### Requirement: 主题可读性

每套主题 SHALL 保证正文、链接、徽章文字、代码高亮、diff 增删着色、焦点环与气泡文字相对其背景达到 WCAG AA（文本 4.5:1，焦点环等非文本 3:1）。这些关键色对 MUST 有自动化测试按主题计算对比度并守护。

#### Scenario: 关键色对达标

- **WHEN** 对每套主题计算正文/气泡/徽章/代码高亮/diff/焦点环与其背景的对比度
- **THEN** 全部达到各自的 AA 阈值，未达标时测试失败

#### Scenario: 深色下强调徽章

- **WHEN** 夜墨主题下渲染带强调色底的徽章（如待回答、待批准标记）
- **THEN** 徽章文字使用该主题的强调底色对应文字色而非固定白色，仍可读

### Requirement: 聊天排版偏好

Web SHALL 允许用户为聊天正文选择：字体（无衬线 / 衬线 / 等宽）、字号（13 / 14 / 16 / 18px）、字重（常规 / 中等 / 偏粗）与行高（紧凑 / 标准 / 宽松），默认依次为无衬线、14px、常规、标准。所有选项 SHALL 是预设档位，不要求键盘输入。字体 SHALL 仅使用系统字体栈，不加载或打包字体文件，所选字体不存在时回退到系统同类字体。

#### Scenario: 默认排版

- **WHEN** 用户从未保存过外观偏好
- **THEN** 聊天正文为无衬线、14px、常规字重、标准行高，与本变更之前一致

#### Scenario: 调整字号

- **WHEN** 用户选择 18px
- **THEN** 用户与助手气泡正文、Markdown 正文与输入框字号变为 18px，Markdown 标题与行内代码按比例缩放，代码块字号不变，且不横向溢出

#### Scenario: 影响范围

- **WHEN** 用户选择衬线字体与偏粗字重
- **THEN** 聊天正文使用衬线字体与偏粗字重（加粗与标题仍比正文更粗），而代码块、工具卡、侧栏与设置页保持原字体与字号

#### Scenario: 选择等宽字体

- **WHEN** 用户选择「等宽」字体
- **THEN** 聊天正文使用等宽字体，代码块与行内代码仍使用既有等宽字体且样式不变

### Requirement: 外观偏好本地持久化

外观偏好 SHALL 仅保存在当前浏览器本地，MUST NOT 经 gateway 发送、写入会话数据或影响 TUI 与移动端。读取到缺失、损坏或取值不在预设范围内的偏好时 SHALL 逐项回落为默认值，不报错。浏览器禁用存储时偏好仅在当前页面生效。偏好变更 SHALL 同步到同一浏览器的其他已打开标签页。

#### Scenario: 刷新后保持

- **WHEN** 用户选择夜墨与 16px 后刷新页面
- **THEN** 页面以夜墨与 16px 显示

#### Scenario: 非法值回落

- **WHEN** 已保存的偏好包含未知主题名或超出预设的字号
- **THEN** 对应项回落为默认值，其余合法项保持不变，界面正常显示

#### Scenario: 多标签页同步

- **WHEN** 用户在一个标签页切换主题
- **THEN** 同一浏览器的其他标签页无需刷新即切换到该主题

#### Scenario: 存储不可用

- **WHEN** 浏览器禁用本地存储
- **THEN** 切换仍在当前页面生效，不弹错误，刷新后回到默认

### Requirement: 首屏应用外观

Web SHALL 在应用渲染前应用已保存的主题与聊天排版，使页面首次绘制即为用户所选，不出现先显示默认主题再切换的闪烁。

#### Scenario: 无闪烁加载

- **WHEN** 已保存夜墨主题的用户打开或刷新 Web UI
- **THEN** 首次绘制的背景即为深色，不先闪现浅色背景

### Requirement: Web 外观设置栏目

Web 设置区 SHALL 提供独立的「外观」栏目（侧栏菜单项，路径 `/settings/appearance`），页面分「主题」与「聊天排版」两组。主题 SHALL 以带小预览的卡片单选呈现；聊天排版各项 SHALL 以一键选择的档位呈现，页面 SHALL 展示一段随选择即时变化的示例对话（用户气泡、助手气泡、行内代码与代码块）。选择即保存即生效，并提供「恢复默认」。所有控件 SHALL 支持键盘与触屏，当前选中项对辅助技术可见。字体项 SHALL 注明实际效果取决于本机已安装字体。

#### Scenario: 即时预览与保存

- **WHEN** 用户在外观页点选「纸白」与 16px
- **THEN** 全站立即切换，示例对话同步变化，无需额外保存操作

#### Scenario: 恢复默认

- **WHEN** 用户点击恢复默认
- **THEN** 主题与全部聊天排版项回到默认值并清除已保存偏好

#### Scenario: 键盘与可访问性

- **WHEN** 用户仅用键盘操作外观页
- **THEN** 可聚焦并切换每个选项，当前选中项以 `aria-checked` 或等价语义暴露
