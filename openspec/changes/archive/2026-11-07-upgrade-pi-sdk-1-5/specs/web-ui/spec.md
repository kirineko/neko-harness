# Spec Delta

## ADDED Requirements

### Requirement: Web 运行失败提示与继续

Web SHALL 在会话空闲且网关提供失败原因时，在输入区上方显示本地化的失败原因（含有界详情），并提供"继续"按钮；按钮在请求进行中禁用，失败时显示本地化错误。失败原因消失（新运行开始）时提示 SHALL 随之消失。网关不提供该字段时 MUST NOT 显示提示与按钮。

#### Scenario: 模型错误后继续

- **WHEN** 运行因模型错误结束，用户点击"继续"
- **THEN** 提示消失，会话进入运行状态，transcript 中不新增用户消息

#### Scenario: 用户停止

- **WHEN** 用户点击停止中止运行
- **THEN** 提示显示为"已停止"并提供继续按钮，用户也可以直接发送新消息

#### Scenario: 旧网关

- **WHEN** Web 连接不提供失败原因字段的旧网关
- **THEN** 不显示提示与继续按钮，其余功能正常
