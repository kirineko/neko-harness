# Spec Delta

## ADDED Requirements

### Requirement: 移动运行失败提示

App SHALL 在会话空闲且快照提供失败原因时，在输入区上方显示本地化的失败原因（含有界详情，按纯文本显示），不提供继续入口；用户可以直接发送新消息。失败原因消失时提示 SHALL 随之消失。快照不提供该字段时 MUST NOT 显示提示。

#### Scenario: 查看失败原因

- **WHEN** 手机查看的会话运行因模型错误结束
- **THEN** 输入区上方显示本地化的"模型错误"及错误文字，发送新消息后提示消失

#### Scenario: 旧电脑

- **WHEN** App 连接不提供失败原因的电脑
- **THEN** 不显示提示，其余功能正常
