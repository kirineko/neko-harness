# Spec Delta

## MODIFIED Requirements

### Requirement: 二次元主题系统

系统 SHALL 使用全站统一的 design tokens，默认主题为蓝粉白「樱花」：导航（侧栏、顶栏、抽屉）、弹层（菜单、目录选择面板、对话框）、聊天内容、输入卡片（含模型入口与遥测控件）与设置页共用同一樱花粉/天依蓝/白 token 体系，滚动条、表单、焦点环和按钮全站一致。用户可在外观设置中切换到其他主题，其他主题 MUST 复用同一套 token 名而不是另建区域样式。正文与控件字号 SHALL 来自统一定义的紧凑字号阶梯；Markdown 行内代码 SHALL 采用中性浅底样式而非主题色药丸；模型输出的 Markdown 渲染前 MUST 经过消毒。

#### Scenario: 默认浅色主题

- **WHEN** 用户从未调整外观并打开 Web UI
- **THEN** 侧栏、顶栏、弹层、聊天区、输入卡片与设置页均呈统一的蓝粉白浅色主题，无中性灰导航区域，正文文本相对背景对比度达到 WCAG AA

#### Scenario: 主题色应用一致

- **WHEN** 界面渲染按钮、链接、状态徽章、聊天气泡、侧栏选中态、滚动条与各级弹层
- **THEN** 颜色、圆角、焦点环与阴影均来自同一套 design tokens，不存在第二套区域主题；切换主题时这些元素一并变化

#### Scenario: 字号与密度阶梯

- **WHEN** 渲染正文、辅助文字、标题与控件
- **THEN** 字号与间距取自统一定义的紧凑阶梯，聊天区正文默认基准为 14px 档（可由聊天排版偏好调整），无散落的一次性硬编码字号

#### Scenario: 行内代码降噪

- **WHEN** 模型回答包含大量行内代码标识符
- **THEN** 行内代码以中性浅底加等宽字体呈现，不使用高饱和主题色药丸，代码块语法高亮不受影响

#### Scenario: 模型输出消毒

- **WHEN** 模型回答中包含 HTML 标签或脚本内容
- **THEN** 界面渲染为无害文本或经消毒的标记，不执行任何脚本

## ADDED Requirements

### Requirement: Web 设置菜单包含外观

Web 设置区侧栏菜单 SHALL 在「模型服务」「联网搜索」「上下文」之后、「手机配对」之前提供「外观」菜单项，指向 `/settings/appearance`，当前页高亮并带 `aria-current`。外观页的外壳、返回聊天入口与窄屏横排行为 SHALL 与其他设置页一致。栏目的具体内容见 `web-appearance` 能力。

#### Scenario: 进入外观页

- **WHEN** 用户在设置页点击「外观」
- **THEN** 路径变为 `/settings/appearance`，菜单项高亮，页面显示主题与聊天排版两组选项

#### Scenario: 窄屏菜单

- **WHEN** 视口为移动宽度
- **THEN** 设置菜单顶部横排，「外观」可点且不遮挡其他菜单项
