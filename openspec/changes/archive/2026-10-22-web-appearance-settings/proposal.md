# Proposal

## Why

Web 端只有一套固定的蓝粉白浅色主题，聊天正文的字体、字号、字重也写死，无法按个人阅读习惯或光线环境调整。长时间阅读模型输出时，用户需要可调的排版，也需要深色选项。

## What Changes

- 设置区新增「外观」栏目（`/settings/appearance`），分「主题」与「聊天排版」两组，全部以一键选择的预设档位呈现，不要求键盘输入。
- 主题：在现有「樱花」（蓝粉白，默认）之外新增「纸白」（中性冷灰白浅色）与「夜墨」（深蓝灰深色）。三套主题共用同一套 token 名，仅替换色阶值，组件不感知主题。
- 聊天排版：字体（无衬线 / 衬线 / 等宽，仅系统字体栈）、字号（13 / 14 / 16 / 18px）、字重（常规 / 中等 / 偏粗）、行高（紧凑 / 标准 / 宽松）。作用于聊天气泡正文、Markdown 正文与输入框；代码块、工具卡、侧栏等不变。
- 偏好保存在浏览器本地（localStorage），首屏渲染前应用以避免闪烁，多标签页同步；提供全部恢复默认。
- 把目前硬编码的颜色（页面渐变背景、logo 渐变、按钮内高光、阴影色调、弹层遮罩、diff 增色、徽章白字、`color-scheme`）改为主题 token，保证三套主题下文字对比度达到 WCAG AA。
- 「二次元主题系统」不再写死「统一蓝粉白」，改为「默认樱花主题 + 可选主题，同一套 token」。

不做：跟随系统（`prefers-color-scheme`）、自定义字体名/颜色、跨设备同步、TUI 与移动端外观设置、应用协议或 gateway 变更。

## Capabilities

### New Capabilities

- `web-appearance`: Web 外观偏好——主题选择、聊天排版偏好的取值范围、本地持久化、首屏应用、跨标签页同步与恢复默认，以及三套主题的可读性保证。

### Modified Capabilities

- `web-ui`: 「二次元主题系统」改为默认樱花主题与可选主题共用同一套 token；新增「Web 外观设置栏目」页面要求。

## Impact

- 代码：`packages/web/src/client/styles.css`（主题变量、聊天排版变量、硬编码色 token 化、`.md` 标题/代码字号改相对单位）、`index.html`（首屏内联脚本与 `color-scheme`）、`settings-shell.tsx` 与 `main.tsx`（新菜单与路由）、新增外观页面、外观偏好 lib 与面板组件、少量组件（`text-white` 徽章、输入框字号）。
- 测试：外观偏好读写/校验单测、主题对比度单测、设置页组件测试；不变更 `layout-tokens.test.ts` 的既有对拍。
- 协议与依赖：无应用协议、gateway、Dart 契约、TUI 变更；无新依赖，不打包字体文件。
