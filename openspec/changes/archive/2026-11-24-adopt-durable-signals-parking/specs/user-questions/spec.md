# Spec Delta

## MODIFIED Requirements

### Requirement: 问答重启恢复与幂等
同一次调用在等待期、回答持久保存后或工具结果提交前中断，恢复 SHALL 复用同一问题及已有决定，不重复提问、不丢失答案；等待回答期间即使进程连续多次异常退出并重开，SHALL 保持未决等待而不消耗任务重启上限、不将等待误判为运行中断。同一调用若以不同题目或选项尝试复用身份 MUST 明确拒绝。会话分叉 MUST NOT 继承可操作的旧未决问题或消费父会话的答案；历史工具结果保持可读。

#### Scenario: 等待期重启
- **WHEN** gateway 在用户回答前退出并重开同一存储
- **THEN** 同一问题仍可回答，身份、版本、正文、选项不变，原调用继续等待

#### Scenario: 等待期连续异常重启
- **WHEN** 问题处于未决等待期间，宿主进程连续异常退出并重开超过任务重启上限次数，随后用户提交有效答案
- **THEN** 问题始终保持未决且不被计为任务崩溃中断，用户提交答案后原调用正常收到答案并继续执行

#### Scenario: 回答后回执丢失
- **WHEN** 答案已持久保存但客户端未收到回执，或工具结果提交前进程退出
- **THEN** 重连查询或重试得到原结算状态，恢复调用使用原答案，不创建新问题或重复模型推进

#### Scenario: 父会话与分叉
- **WHEN** 用户在包含问题历史的会话中创建分叉
- **THEN** 分叉不显示父会话的可操作未决问题，无法用父问题身份向分叉提交答案；已有历史答案不被改写
