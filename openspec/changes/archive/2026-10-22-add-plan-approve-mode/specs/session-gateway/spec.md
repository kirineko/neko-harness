# Spec Delta

## ADDED Requirements

### Requirement: 计划模式视图与决定接口
网关 SHALL 在会话视图中以可选字段发布规划状态（当前模式、当前计划版本、步骤、状态与修订序号），并提供读取计划、批准、要求修改与进入/退出 plan 模式的接口。字段缺省表示网关不支持，不得被解释为"无计划"；支持但无计划时字段存在且计划为空。接口 MUST 校验会话归属、计划版本与反馈长度，错误身份、过期版本与越界输入明确拒绝且不泄漏其他会话内容。该能力 MUST NOT 提升应用协议版本。

#### Scenario: 支持与旧网关
- **WHEN** 新客户端连接支持计划的网关与不支持的旧网关
- **THEN** 前者发布计划字段（可为空），后者字段缺省，客户端据此隐藏计划入口且不调用相关接口

#### Scenario: 多客户端共享
- **WHEN** 两个客户端观察同一会话，其中一个批准计划
- **THEN** 两端视图都更新为已批准，会话模式与工具集一致变化

#### Scenario: 错误版本或会话
- **WHEN** 客户端提交过期版本、未知版本或属于其他会话的计划决定
- **THEN** 请求被拒绝，不改变任何会话的模式或计划状态

### Requirement: 会话目录等待批准标记
会话摘要 SHALL 以可选字段标明会话是否有待批准计划，缺省表示网关不能判断。该标记 MUST 与等待回答标记独立：待批准期间会话不处于运行中，批准、要求修改、取消或取代后标记清除。

#### Scenario: 待批准可发现
- **WHEN** 用户在另一个会话中查看会话列表
- **THEN** 有待批准计划的会话带有明确标记，用户无需进入会话即可发现

#### Scenario: 决定后清除
- **WHEN** 该计划被批准、要求修改或取消
- **THEN** 标记在下一次列表快照中清除
