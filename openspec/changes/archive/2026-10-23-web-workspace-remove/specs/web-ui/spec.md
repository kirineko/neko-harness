## ADDED Requirements

### Requirement: Web 工作区切换器移除入口

Web 工作区切换器 SHALL 为每个可移除的工作区提供移除入口：桌面端在行悬停或键盘聚焦时显示，触屏设备常驻显示；入口 MUST 有包含目录名称的可访问名称与悬停提示，并且不触发切换工作区。不可移除的工作区（Web 的启动目录、目录中仅剩的最后一个工作区）SHALL 隐藏入口或置灰，并给出原因说明。移除入口在 375 像素窄屏上无横向溢出，长路径照常折行。

#### Scenario: 悬停与聚焦显示

- **WHEN** 用户在桌面端把指针移到工作区行上，或用键盘 Tab 到该行的移除按钮
- **THEN** 移除按钮出现并可见焦点；点击它不会切换工作区

#### Scenario: 触屏常驻

- **WHEN** 用户在触屏设备上打开工作区切换器
- **THEN** 每个可移除的工作区行显示移除按钮，触控区足够大且不与切换主按钮重叠

#### Scenario: 不可移除原因

- **WHEN** 工作区是 Web 的启动目录，或目录中只剩一个工作区
- **THEN** 该行的移除入口置灰或隐藏，并说明启动目录无法移除或至少需保留一个工作区

### Requirement: Web 工作区移除确认与结果

点击移除入口 SHALL 先弹出确认框，写明工作区名称与完整路径，并说明"不删除磁盘文件、其下会话将被隐藏、重新添加该目录后恢复"，并展示将被隐藏的非归档会话数。确认框提供取消与确认，提交期间锁定并防止重复提交；服务端拒绝时 SHALL 在框内显示可理解的原因且保留工作区。成功后若被移除的是当前工作区，Web MUST 自动切换到目录中的另一个工作区并恢复其最近使用会话；移除其他工作区 MUST NOT 改变当前会话、草稿与选择。

#### Scenario: 确认移除当前工作区

- **WHEN** 用户在当前工作区行点击移除并确认
- **THEN** 工作区从切换器消失，Web 切换到目录中的下一个工作区，聊天区与会话列表反映新工作区，不残留已移除工作区的会话

#### Scenario: 移除其他工作区

- **WHEN** 用户移除非当前工作区
- **THEN** 当前会话、输入草稿、附件与滚动位置不变

#### Scenario: 被服务端拒绝

- **WHEN** 确认时该工作区已有会话正在运行，或最后一个工作区已被其他客户端占用
- **THEN** 确认框显示拒绝原因，工作区仍在切换器中，可取消或关闭后重试

#### Scenario: 取消与多语言

- **WHEN** 用户取消或按 Esc 关闭确认框，或界面语言为 English
- **THEN** 没有任何变更，焦点回到触发的控件；确认框、按钮、提示与错误随界面语言显示

#### Scenario: 其他客户端同时移除

- **WHEN** 当前工作区被另一个客户端移除
- **THEN** Web 在收到更新后的工作区目录时自动切到另一个工作区，不停留在已不存在的工作区，也不向已隐藏会话发送输入
