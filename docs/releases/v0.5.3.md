**新增**

- 新增 codemode：模型可以编写 JavaScript 脚本，在 QuickJS 沙箱中批量、链式调用工具，只把脚本筛选后的输出带回对话，减少多轮工具调用和中间结果占用的上下文。脚本在运行中遇到网关重启后可恢复，已完成的嵌套工具调用不会重复执行
- 提供 `off` / `on` / `only` 三种模式，默认 `off`。可通过 Web「设置 → Codemode」、TUI `/codemode` 或配置文件 `codemode.mode` 修改；`on` 同时提供普通工具和脚本工具，`only` 主要由脚本调用其他工具。设置只影响之后新建的会话，已有会话保持不变
- Web、TUI 和移动端的 codemode 工具卡展示脚本与嵌套调用；Markdown、HTML、JSON 导出同样保留这些内容。脚本中成功的文件编辑也会计入「本次改动」
- 嵌套调用沿用原有安全边界：plan 模式只读限制和 explore 子 agent 的 Bash 逐次审批仍然生效。沙箱最多同时运行 2 个 worker、每个限 256 MiB，排队等待上限 60 秒

**兼容性**

- 桌面端应用协议从 9 升到 10：网关与 Web / TUI 客户端需一同升级，协议不同的连接会被拒绝
- 移动端 API 保持 v1 不变；移动端只新增 codemode 卡片展示，没有设置入口
- codemode 默认关闭，未启用时的现有会话和工具行为不变；升级前创建的会话按 `off` 处理
- 脚本不提供分类器和图片生成等 `models.*` 能力，避免绕过模型服务的启用与凭据限制

**内部**

- 基于 Pi 1.4.0 的 `pi-durable/codemode` 与 `pi-codemode`，新增直接依赖并继续精确锁定版本
- 完成 core、网关、Web、TUI、移动端及发布包测试；OpenSpec 变更 `add-codemode` 已归档
