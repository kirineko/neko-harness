**新增**

- 全局 MCP 服务器支持：通过 `~/.neko/mcp.json` 统一配置（所有工作区共用），支持 `stdio` 本地进程与 Streamable HTTP 远程服务（显式拒绝已废弃的 `sse` 与 `"cimd"` 方式）；支持 `${NAME}` 环境变量模板运行时展开（磁盘保留原始模板）、原子写盘与目录级热重载（配置损坏时保留上次有效配置并展示诊断）
- 远程 MCP OAuth 2.1 认证：自动识别需要 OAuth 的远程 HTTP 服务器并隐藏公开免认证服务的登录入口，支持浏览器本地回调与粘贴重定向 URL 两段式登录；凭据以 `0600` 权限独立存于 `~/.neko/mcp-auth.json`，支持进程内静默刷新，前端与状态快照零令牌泄露
- Web 端新增 `/settings/mcp` 设置页：支持服务器卡片列表、实时连接状态、折叠查看工具列表与 `stderr` 日志、表单与原始 `mcp.json` 双模式编辑、敏感字段遮罩以及一键重连和 OAuth 登录/退出
- TUI 新增 `/mcp` 管理面板：支持查看状态、启停、重连及 OAuth 登录流程（含 `/mcp paste <url>` 与 `/mcp cancel`）；Web 与 TUI 工具卡统一优化 `mcp__*` 与 `tool_search` 展示

**实现说明**

- 与 `codemode` 及 `tool_search` 联动：无已启用服务器时保持零开销；`codemode: off` 时按 `exposure`（`auto` 延迟发现 / `direct` 直接声明）提供 `tool_search` 与 `mcp_servers` 提示词段；`codemode: on/only` 时自动切换为按服务器命名空间（`mcp__<server>`）调用，脚本侧获取完整结构化结果，模型侧按 20 KB 截断并落盘完整输出
- 连接池与护栏：每个启用服务器复用单一连接、后台非阻塞连接并按 1s–60s 指数退避重连，监听 `notifications/tools/list_changed` 自动刷新工具并在退出时优雅关闭子进程；`plan` 模式双层拦截未声明 `readOnlyHint: true` 的 MCP 工具，进出 `plan` 保留已加载工具；仅 `coder` 子 agent 继承 MCP 工具，`explore` / `plan` 子 agent 默认隔离

**兼容性**

- 桌面端应用协议从 11 升至 12（新增 `neko.mcp` Chord v2 契约）：升级后若旧网关仍在运行，需要退出重开；网关与 Web / TUI 客户端须一同升级
- 移动端 API 保持 v1 不变，移动端 App 无需更新（不新增移动端 MCP 配置入口）
- 既有的 `~/.neko/neko.sqlite` 无需迁移，原样兼容
